# Changelog

## [0.15.0] - 2026-10-22

### Added
- Human-in-the-loop (HITL) support for ReliableAgent and Graph interrupts
- Production-ready interrupt points before critical steps

### Improved
- Cleaner agent lifecycle (plan → execute → replan → reflect)
- Better multi-agent coordination and shared memory

## [0.14.0] - 2026-09

- Graph v2 with loops, conditionals, and persistence
- Multi-agent Crew modes (parallel / sequential)
- Expanded RAG loaders and vector stores

## [0.10.0] - 2026-08

- ReliableAgent with reflection loop
- Retry / Fallback model wrappers
- Output parsers (JSON, Pydantic, List)

## Earlier

Initial agents, tools, memory, and basic RAG support.
